# Flashcard Generator
Frontend only: React, Redux, Formik, react-router-dom, react-icons, Tailwind. Data persists in localStorage.

    npm install
    npm run dev      # start
    npm test         # React Testing Library tests
    npm run build    # deploy the dist/ folder to Netlify / Vercel / Heroku static

For SPA routing on a host, redirect all paths to index.html.
